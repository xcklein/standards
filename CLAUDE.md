# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

This repository contains Christian Klein's personal coding standards — documents and rules to be referenced by AI coding tools (Claude Code, Cursor, Copilot, etc.) across projects. It is not a software project with build steps or tests; it is a living reference.

## Structure

Standards are organized as Markdown documents. When adding or editing standards:

- Keep each standard focused on a single language, framework, or domain.
- State rules as concrete directives, not general advice.
- Include rationale only when the rule is non-obvious.
- Avoid restating things any competent developer already knows.

## How to Reference These Standards

To apply these standards in another project, either:

- Symlink or copy the relevant files into that project's `.claude/` or root directory, or
- Reference them in that project's `CLAUDE.md` with a note pointing here.
